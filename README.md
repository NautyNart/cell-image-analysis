# DATA3888 — Breast Cancer Tumour Subtype Analysis

This repository contains the full pipeline for cell-image-based tumour subtype classification, including exploratory data analysis (EDA), model training (ResNet-50, ViT, CTransPath), and an interactive Shiny web app for inference and result exploration.

## Setup

### 1. Install dependencies

Requires **Python 3.10+**. Run from the repository root:

```bash
pip3 install -r requirements.txt
```

> **Note:** For PyTorch with GPU support, visit [pytorch.org](https://pytorch.org/get-started/locally/) and install the appropriate CUDA version **before** running the above.

---

## Running the Shiny App

### Step 1 — Download the fine-tuned model weights

The `.pth` model weight files are too large for Git and are hosted on Google Drive.  
Run the following **once** from inside the `final/` folder:

```bash
cd "Final Shiny product/final"
python3 download_models.py
```

This will download the three weights into `Final Shiny product/final/models/`:
- `100px_best_model.pth` — CTransPath fine-tuned on 100px patches
- `50px_best_model.pth` — CTransPath fine-tuned on 50px patches
- `masked_best_model.pth` — CTransPath fine-tuned on 100px masked patches

### Step 2 — Launch the app

```bash
cd "Final Shiny product/final"
python3 -m shiny run app.py
```

Then open **http://127.0.0.1:8000** in your browser.

### App tabs

| Tab | Description |
|---|---|
| **Tab 1 — Background** | Research context, dataset overview, and cell type reference guide |
| **Tab 2 — Classifier** | Upload a cell image → get a live tumour subtype prediction with confidence scores |
| **Tab 3 — Model Comparison** | Interactive charts comparing ResNet-50, ViT, and CTransPath metrics |

> **Sample images** for Tab 2 are in `Final Shiny product/images/`. Each subfolder (e.g. `cell_100032/`) contains three patch versions: `_100.png`, `_100_masked.png`, and `_50.png`.

## Running the Notebooks

### Step 1 — Prepare the image data

Unzip the image archives into `image_data/`:

```bash
cd image_data
unzip Tumours.zip    # creates image_data/Tumours/{DCIS_1, DCIS_2, Invasive_Tumor, Prolif_Invasive_Tumor}/
unzip Archive.zip    # creates image_data/50/{DCIS_1, DCIS_2, Invasive_Tumor, ...}/
```

Place the metadata files into `image_data/metadata/`:

```
image_data/metadata/
├── 41467_2023_43458_MOESM4_ESM.xlsx   ← Supplementary data given
├── cbr.csv
├── cell_boundaries.csv
└── threepts.csv
```

> **No path editing is needed** in the notebooks. Each notebook's config cell auto-detects Kaggle vs local and sets paths relative to the repo root.

---

### Step 2 — Download the CTransPath backbone weights (`ctranspath.ipynb` only)

The pre-trained CTransPath backbone is required for fine-tuning. Download `ctranspath.pth` and place it at:

```
Modelling/CTransPath/ctranspath.pth
```

Download: https://drive.google.com/file/d/1DoDx_70_TLj98gTf6YTXnu4tFhsFocDX/view

---

### Step 3 — Run notebooks in order

| # | Notebook | Output | Requires |
|---|---|---|---|
| 1 | `EDA + Preprocessing/data3888-eda.ipynb` | EDA figures | image data + metadata |
| 2 | `EDA + Preprocessing/data-preprocessing.ipynb` | `image_data/preprocessing_results/` | image data + metadata |
| 3 | `Modelling/resnet-50-2.ipynb` | ResNet-50 results | step 2 output |
| 4 | `Modelling/ViT/Vit_code.py` | ViT results | step 2 output |
| 5 | `Modelling/CTransPath/ctranspath.ipynb` | CTransPath results | step 2 output + backbone weights |

> Notebooks were originally trained on **Kaggle with GPU**. Local training is possible but will be significantly slower without a GPU.
